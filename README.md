## 📌 Project Overview / প্রজেক্ট ওভারভিউ

**English:**  
`Auto Viewer Bot` is an automated Node.js script (`auto_viewer.js`) designed to handle automated viewing and interaction tasks seamlessly using dependencies configured in `package.json`.

**বাংলা:**  
`Auto Viewer Bot` হলো একটি স্বয়ংক্রিয় Node.js টুল (`auto_viewer.js`), যা অটোমেটিক ভিউ বা টাস্ক সম্পন্ন করার জন্য তৈরি করা হয়েছে। এটি `package.json` ফাইলের ডিফাইন করা ডিপেন্ডেন্সি ব্যবহার করে খুব সহজে ও দ্রুত কাজ করে।

---

## ⚙️ Features / ফিচারসমূহ

- ⚡ **Automated Execution:** Runs tasks automatically without manual intervention.
- 🛠️ **Easy Setup:** Simple setup process with minimal requirements.
- 🎯 **Lightweight & Fast:** High performance powered by Node.js.
- 📱 **Termux / Mobile & PC Compatible:** Runs smoothly on Android (via Termux), Linux, Windows, and macOS.
